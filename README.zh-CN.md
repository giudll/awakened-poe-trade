# Awakened PoE Trade · 简体中文版

面向 **国际服 + 编年史简体补丁** 的流放之路 1 查价工具。基于上游
[SnosMe/awakened-poe-trade](https://github.com/SnosMe/awakened-poe-trade) 改造，
只做一件事：让简中客户端能用**中文词缀**查价，界面也是中文。

## 下载安装（你只需要做这一步）

1. 打开 **[最新版本下载页](../../releases/latest)**
2. 下载其中一个：
   - `AwakenedPoE-Trade-zh-Setup-*.exe` —— 安装版，有开始菜单和桌面图标，之后能自动更新
   - `AwakenedPoE-Trade-zh-Portable-*.exe` —— 便携版，双击就能用，不写注册表
3. 双击运行。

第一次启动时如果 Windows 弹出蓝色的"已保护你的电脑"，点 **更多信息 → 仍要运行**。
这是未购买代码签名证书的正常提示，不影响使用。

装好后界面就是简体中文，`设置 → 常规 → 语言` 里显示"简体中文（编年史）"。

## 怎么查价

1. 在 `设置 → 快捷键` 里确认查价快捷键（常用 `Ctrl + D`，自己改也行）
2. 游戏里把鼠标移到物品上，按 `Ctrl + C` 复制物品文本
3. 按查价快捷键 → 弹出词缀列表 → **勾选你关心的词缀** → 回车发送

弹出窗口里的词缀默认**一条都不勾**，需要你自己挑。这是故意的：国际服市集有查询频率
限制，把整件装备的词缀全塞进一次查询既慢又容易被限速。

中英混排的物品也能查：中文词缀会先转成对应的英文词缀，再和你勾选的英文词缀一起发给
市集，两边查到的是同一件东西。

## 更新

- 每次这边打包出新版本，**正在运行的程序会弹一条系统通知**（右下角），点通知直接
  打开下载页；也可以在 `设置 → 关于` 里手动点"检查更新"。
- 覆盖安装新版本即可，配置、快捷键、窗口位置都会保留。
- 便携版不会自动下载，只会提示你去下载页换新的 exe。

## 汉化范围（请先看这一段）

| 内容 | 语言 |
|---|---|
| 查价词缀、物品名、地图名 | 来自编年史简体补丁，和游戏里看到的完全一致 |
| 软件界面、托盘菜单、通知 | 简体中文 |
| 编年史尚未汉化的新词缀 | **保持英文** |

最后一条不是偷懒：这些词缀在游戏里本来就显示英文，如果这里硬翻成中文，程序拿中文去
市集就匹配不到东西，反而查不到价。所以凡是编年史没翻译的，一律保留英文原文。

本仓库不合并其他第三方汉化，也不猜测词缀译文。

## 自动跟进（不需要你操作）

仓库每天自动检查两个来源：

| 情况 | 自动行为 |
|---|---|
| 编年史补丁更新了 | 只重建中文词缀/物品数据，然后重新打包 |
| 上游 APT 有新提交 | 合并上游代码 → 重建数据 → 重新打包 |
| 两边都没更新 | 什么都不做 |

每次打包都会生成一个新版本号并发布到 Releases，所以运行中的软件能收到更新提醒。

## 常见问题

- **某些词缀还是英文**：编年史没汉化，游戏内也是英文，属于预期行为。
- **赛季列表加载失败**：见 [docs/failed-load-leagues.md](./docs/failed-load-leagues.md)
- **查价没反应**：确认游戏窗口是当前焦点，并检查快捷键是否被游戏占用。
- **想要纯英文原版**：请到[上游 Releases](https://github.com/SnosMe/awakened-poe-trade/releases) 下载。
